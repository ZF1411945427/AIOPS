## 一、任务目标

在 **架构巡检图（`FireMapView.vue`）** 点进某个业务域后，加一个「生成架构图」按钮 → 弹出配置（导出格式：`.drawio`/PNG/SVG/PDF + draw.io 本地安装路径）→ 点击生成 → 生成**当前业务域资产的系统架构图**（分层 + 父子归属 + 依赖连线），交付 draw.io 可编辑源文件，可选本地 drawio 无头导出图片。

## 二、需求来源与背景调研（已完成）

- 用户提供 `D:\AIOPS\skills\drawio-scientific-illustrator-main.zip`（已解压到 `C:\Users\zhuming\AppData\Local\Temp\opencode\drawio_skill\drawio-scientific-illustrator-main\` 供参考，可删）。
- 调研结论：这是一个 **Codex 插件 + MCP 服务器**，通过 localhost MCP 实时控制**本机 draw.io 桌面版画布**（`drawio_live_add_shape`/`add_edge`/`save_snapshot` 等），依赖 Codex 运行时 + draw.io 桌面 + Node 22 + 可见画布，且明确"不先生成 XML"。
- **结论：MCP/桌面实时画布依赖不适用于本 Web 系统（FastAPI + Vue）**。只借鉴其 `.drawio` 的 mxGraph 图元约定，**自研 Python 生成 `.drawio` XML**，再用本地 drawio 命令行无头导出 PNG/SVG/PDF（`drawio.exe --export --format xxx --output yyy input.drawio`）。本机未装 draw.io，故由用户在弹窗里配置路径。

## 四、后端实现（已完成，已验证）

### 4.1 `app/services/drawio_generator.py`（新建，约 360 行）

核心函数：
- `_ci_layer(ci_type) -> str`：ci_type → 显示层（`1`接入/`2`应用/`3-mq`中间件/`3-db`存储/`4`基础设施/`k8s`容器编排）。有 `CI_LAYER` 字典 + 按集合回退。
- `collect_domain_assets(db, domain) -> List[Asset]`：按域过滤资产（复用 `_extract_domains`）。
- `build_drawio_xml(domain, assets, relations, diagram_title) -> str`：生成 draw.io mxGraph XML。
  - 布局：每层一行，节点水平等距（CARD_W=150, CARD_H=46, GAP_X=24, LAYER_GAP=70），整体居中。层级容器带标题虚线框（bg-id）。
  - 节点：id=`n{id}`，style 含 `fillColor={层色};strokeColor={健康色}`。健康色 `_asset_health_color`（green 绿/red 红/warning 橙/gray 灰）。
  - 关系边：id=`e{id}`，`edgeStyle=orthogonalEdgeStyle`，`source/target` 引用 `n{id}`，样式按 `RELATION_STYLE` 映射颜色（routes_to 蓝/depends_on 红/member_of 绿/connected_to 紫）+ 边标签。
  - **父子归属线**：遍历资产，对有 `parent_id`（且非 0/None、父在集合内、不与关系边重复）的节点，画 `id=h{id}` 灰色虚线，标签 `in`。
- `export_via_drawio(drawio_path, drawio_file, fmt, out_dir, timeout) -> (ok, msg, out_path)`：调本地 draw.io CLI 无头导出 PNG/SVG/PDF/JPG。校验路径存在、格式合法；用 `subprocess.CREATE_NO_WINDOW`。
- `render_meta(domain, assets, relations) -> dict`：元信息（资产数/关系数/各层成员/ci_types/health）。
- 路径规范：`EXPORT_ROOT = os.environ.get("AIOPS_ARCH_DIR", str(PROJECT_ROOT/"generated"/"architecture"))`；`PROJECT_ROOT = Path(__file__).resolve().parent.parent.parent`。

### 4.2 `app/routers/arch_diagram.py`（新建，约 120 行）

- `GET /api/arch-diagram/meta?domain=xxx`：返回 `render_meta`（前端弹窗预览用）。如无资产返 `{ok:False, message}`。
- `POST /api/arch-diagram/generate`，body `{domain, drawio_path?, format?}`：
  1. 生成 `.drawio` XML，落盘 `generated/architecture/arch-{safe}.drawio`；
  2. 若 `format != drawio` 且有 `drawio_path` → 调 `export_via_drawio`；返回 `drawio_download`（文件下载 URL）。
- `GET /api/arch-diagram/list`：列出 `generated/architecture/` 下文件。
- `GET /api/arch-diagram/file/{filename}`：下载（FileResponse，含防穿越，media type 按扩展名映射）。

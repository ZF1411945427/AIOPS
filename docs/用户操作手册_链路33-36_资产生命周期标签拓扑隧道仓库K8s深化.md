# 链路33：资产生命周期 & 标签管理 & 拓扑视图

## 第一步：资产生命周期

### 操作页面
**侧边栏** → **资源管理** → **资产管理** → **资产生命周期**

### 操作步骤

1. **查看状态机**
   - 状态机流转图：`provisioning → active → maintenance → retired`

2. **资产流转**
   - 点某资产「流转」→ 弹窗选目标状态 + 备注 → 确认 → POST `/lifecycle/api/transition/{id}`
   - 终态（retired）资产的流转按钮置灰

3. **查看历史**
   - 点「历史」→ GET `/lifecycle/api/history/{id}` 查看状态变更时间线

## 看到什么
- 状态机流转图 + 资产列表（含当前生命周期状态）+ 流转弹窗 + 历史时间线

---

## 第二步：标签管理

### 操作页面
**侧边栏** → **系统配置** → **系统管理** → **标签管理**

### 操作步骤

1. **分类管理**
   - 左侧分类列表，点「+ 新建分类」或 ✏️ 编辑分类

2. **标签管理**
   - 右侧搜索/排序，点「+ 新建标签」或卡片 ✏️ / 🗑️ → POST `/tags/api`

3. **查看关联资产**
   - 点卡片底部「查看资产」→ 展开关联资产 → 「移除标签」→ POST `/tags/api/remove`

## 看到什么
- 左侧分类列表 + 右侧标签卡片网格 + 标签关联资产面板

---

## 第三步：拓扑视图

### 操作页面
**侧边栏** → **资源管理** → **资产管理** → **拓扑视图**

### 操作步骤

1. **资产拓扑 Tab**
   - 统计卡 + 工具栏（类型筛选/搜索/仅异常/+ 新增关系/刷新/自动刷新）
   - 点拓扑节点 → 右侧显示节点详情与关联资产

2. **新增/删除关系**
   - 「+ 新增关系」选源/目标/关系类型 → POST `/topology/api/relations/create`
   - 关系列表点「删除」→ POST `/topology/api/relations/{id}/delete`

3. **网络拓扑 Tab**
   - 模式切换：设备关系 / IP 网段

4. **服务调用 Tab**
   - 时间范围 1h/6h/24h/7d/全部 → 查看服务调用拓扑

5. **自动刷新**
   - 开启「自动刷新」每 30s 拉取一次

## 看到什么
- 3 个 Tab（资产拓扑/网络拓扑/服务调用）+ 图例 + 节点详情

## 链路33 补充：路径查询

### 操作页面
**侧边栏** → **资源管理** → **资产管理** → **路径查询**

### 操作步骤

1. **选择源/目标节点**
   - 页面进入自动加载可用节点（GET `/topology/api/list`）
   - 在「查询条件」面板选源节点 → 目标节点

2. **查找路径**
   - 点「查找路径」→ POST `/topology/api/path/find`（body 传 `source_id`/`target_id`）
   - 后端 BFS 求最短路径，返回 `nodes`/`edges`/`path`

3. **查看结果**
   - 跳数/节点数摘要 + 垂直路径列表（每跳显示关系类型 relation_type）
   - 异常节点（status offline/error/critical）红色描边
   - ECharts 力导向图可拖拽/缩放，绿边=起点、红边=终点

### 看到什么
- 「查询条件」面板 + 「查询结果」面板（路径列表 + 力导向图）

# 链路34：Edge 隧道管理 & 离线仓库

## 第一步：Edge 隧道管理

### 操作页面
**侧边栏** → **资源管理** → **资产管理** → **Edge 隧道管理**

### 操作步骤

1. **生成 Token**
   - 「🔐 生成新 Token」→ 复制 → 目标主机运行：`python edge_agent.py --cloud <url> --token <token>` → POST `/edge/tokens`

2. **管理在线会话**
   - **WebSSH 终端**：在线会话点终端（WS `/webssh/{agent_id}?token=...`）进入
   - **快速命令**：whoami / hostname / uptime
   - **绑定资产**：将 Edge 会话绑定到现有资产 → POST `/edge/sessions/{id}/bind`
   - **删除**：解除会话 → DELETE `/edge/sessions/{id}`

3. **命令测试**
   - 顶部命令测试区执行一次性远程命令（超时 30s）→ POST `/edge/command`

## 看到什么
- 概览三卡（设备纳管/隧道 Token/命令测试）+ Edge 会话列表 + 命令审计日志 + WebSSH 终端

---

## 第二步：离线仓库

### 操作页面
**侧边栏** → **资源管理** → **资产管理** → **离线仓库**

### 操作步骤

1. **上传离线包**
   - 「⬆ 上传离线包」→ 选 `.tar.gz`（可拖拽）+ 填名称/类型/系统/版本/MD5 → POST `/offline/api/bundles/upload`

2. **加载离线包**
   - 卡片「加载」→ 解压导入镜像/生成包源；「镜像」/「包源」查看；「删除」

3. **私有镜像仓库**
   - 「＋ 添加仓库」→ 填地址/协议/账号密码/内嵌/默认 → 可「测试连接」「镜像列表」「编辑」「删除」

4. **健康状态**
   - 「重新检查」→ 查看各仓库/镜像源可达性 → GET `/offline/api/health`

## 看到什么
- 4 个 Tab（离线包/私有镜像仓库/系统包源/健康状态）+ 各操作弹窗

# 链路35：K8s 监控 & 证书巡检

## 第一步：K8s 资源监控

### 操作页面
**侧边栏** → **智能分析室** → **指标监控** → **K8s 资源监控**

### 操作步骤

1. **选择集群与时间范围**
   - 选集群（默认全部）+ 时间范围（1-24h）+ 刷新

2. **查看监控**
   - 3 个统计卡（节点/Pod/Deployment）+ 三张时序折线图（CPU/内存使用率、Pod 重启次数）→ GET `/k8s-monitor/api/list?cluster=&hours=`

## 看到什么
- 折线图悬浮显示精确值；可前往告警管理设置阈值；数据来自 MetricRecord 采集任务

---

## 第二步：K8s 证书巡检

### 操作页面
**侧边栏** → **资源管理** → **K8s 资源** → **证书巡检**

### 操作步骤

1. **开始巡检**
   - 选集群 → 点「开始巡检」→ POST `/k8s/cert/api/inspect`
   - 扫描各发行版证书有效期：正常 >90 天 / 预警 31-90 / 临期 ≤30 / 过期

2. **一键续期**
   - 点「一键续期」→ 可勾「强制续期」→ 确认执行对应发行版续期命令（云托管不支持）→ POST `/k8s/cert/api/renew`

## 看到什么
- 汇总统计卡（证书总数/正常/预警/临期/过期）+ 证书有效期清单表 + 续期结果面板

# 链路36：K8s 资源管理深化

## 第一步：集群总览

### 操作页面
**侧边栏** → **资源管理** → **K8s 资源** → **集群总览**

### 操作步骤

1. **查看集群状态**
   - 顶部统计卡（集群/节点/Pod/Deployment/命名空间/Service）+ 集群卡片网格 → GET `/k8s/api/overview`

## 看到什么
- 集群卡片网格（状态点/端点/采集时间/指标/健康率）

## 第二步：Pod 与 Deployment 管理

### 操作页面
**侧边栏** → **资源管理** → **K8s 资源** → **Pod 容器组** / **Deployment 应用**

### 操作步骤

1. **Pod 管理（k8s-pods）**
   - 筛选集群/命名空间 → Pod 列表

### 看到什么
- Pod 列表（详情/日志/终端/Describe）、Deployment 列表（管理各项操作）

## 第三步：统一资源列表

### 操作页面
**侧边栏** → **资源管理** → **K8s 资源** → **Namespace 命名空间**（及 StatefulSet/DaemonSet/Service/Ingress/ConfigMap/Secret/HPA/PVC 等）

### 操作步骤

1. **切换资源类型**

## 链路36 补充：容器管理（Docker & Helm）

> 入口：**资源管理 → 容器管理**，含「容器总览 / 容器列表 / Helm Release」三个页面。

### A. 容器总览

**侧边栏** → **资源管理** → **容器管理** → **容器总览**
- 纯只读概览，进入自动加载 → GET `/containers/api/overview`
- 统计卡：容器总数 / 运行中 / 已停止 / Docker 主机
- 主机分布面板（运行/停止比例）+ 热门镜像 Top5 + 最近创建容器表格
- 「📖 操作说明」查看状态颜色说明（运行/停止/暂停/异常）

### B. 容器列表

**侧边栏** → **资源管理** → **容器管理** → **容器列表**
1. **筛选查询**：容器名/主机/状态 → 点「查询」→ GET `/containers/api/docker?search=&host=&status=`
2. **扫描本地 Docker**：导入本机容器 → POST `/containers/api/docker/local/scan`
3. **详情 / 日志 / 终端**：
   - 详情：容器信息 + attrs 完整属性
   - 日志：选行数（100-5000）/关键字过滤/刷新 → GET `/containers/api/docker/{id}/logs`
   - 终端：xterm WebSocket 在线终端

### C. Helm Release

**侧边栏** → **资源管理** → **容器管理** → **Helm Release**
1. **仓库管理 Tab**：添加仓库（名/URL）、更新仓库索引、删除仓库
2. **安装应用 Tab**：选集群/Release名/Chart名/命名空间/版本 + Chart 搜索 → 可选 Values YAML →「安装/升级」→ POST `/helm/api/install`、`/upgrade`
3. **Release 管理**：查询 → 「查看」详情（含 Revision 历史）→「回滚」选 Revision →「卸载」

### 看到什么
- 容器总览统计卡与镜像分布、容器列表与在线终端、Helm Release 列表与安装/回滚

## 常见问题

### Q1：资产生命周期无法流转到终态？
- **检查**：该资产是否处于终态（retired）导致按钮置灰

### Q2：Edge 会话不在线？
- **检查**：主机是否运行 `edge_agent.py` 且 Token 有效；反向隧道连通性

### Q3：离线包加载失败？
- **检查**：压缩包格式（.tar.gz）、MD5 是否一致、磁盘空间是否充足

### Q4：证书巡检云集群不支持续期？
- **说明**：云托管（EKS/ACK 等）证书由云平台管理，不支持一键续期

### Q5：K8s 资源列表无数据？
- **检查**：集群连接是否正常、命名空间是否选择、是否有对应资源类型

## 专业术语

| 术语 | 英文 | 说明 |
|------|------|------|
| 生命周期 | Lifecycle | 资产状态机：provisioning→active→maintenance→retired |

| 离线仓库 | Offline Repo | 离线包 + 私有镜像仓库 + 系统包源的离线分发 |
| 证书巡检 | Cert Inspection | K8s 证书有效期分级巡检与一键续期 |
| 金丝雀发布 | Canary | 先小流量验证再全量升级的发布方式 |

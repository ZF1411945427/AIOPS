# AIOps 用户操作手册 — 链路41-44：安全治理 & 平台管理 & 通知集成 & 系统态势

> **适用角色**：系统管理员、安全管理员、审计员
> **前置条件**：已登录系统，拥有相关菜单权限
> **预计耗时**：约 30-40 分钟

---

## 概述

本手册覆盖四条链路（补齐安全、合规与平台治理类功能页）：

- **链路41**：凭据保险库 + 安全自查
- **链路42**：审计覆盖矩阵 + 字段契约检测 + 后台任务看板
- **链路43**：租户管理 + 开放接口 + 集成管理
- **链路44**：通知管理 + 系统态势

> **链路41 安全**　①凭据保险库 → ②安全自查
> **链路42 审计治理**　①审计矩阵 → ②契约检测 → ③后台任务
> **链路43 平台**　①租户 → ②开放接口 → ③集成
> **链路44 监控**　①通知管理 → ②系统态势

# 链路41：凭据保险库 & 安全自查

## 第一步：凭据保险库

### 操作页面
**侧边栏** → **系统配置** → **系统管理** → **凭据保险库**

### 操作步骤

1. **新建凭据**
   - 填引用名（英文）+ 类型（password/token/api_key/private_key/custom）+ 作用域（global/data_source/asset）+ 值 → 保存 → POST `/api/vault/secrets`
   - 复制引用标记 `{{secret:name}}`

2. **编辑 / 删除**
   - 编辑：**值留空=不修改**，仅加密存储不回显（敏感字段契约）
   - 删除：提示影响引用数据源后确认

3. **解析测试**
   - 引用解析测试面板：输入含 `{{secret:name}}` 的 JSON → 点「解析」验证替换为真实值 → POST `/api/vault/secrets/resolve`

### 看到什么
- 凭据表格（引用名/类型/作用域/值掩码）+ 数据源引用一览 + 引用解析测试面板

---

## 第二步：安全自查

### 操作页面
**侧边栏** → **系统配置** → **系统管理** → **安全自查**

### 操作步骤

1. **查看缓存报告**
   - 进入先读缓存报告（秒级）→ GET `/api/security-audit/report`

2. **重新全量扫描**
   - 「重新全量扫描」→ 执行 bandit + pip-audit + pip-licenses（首次约 1-3 分钟）→ POST `/api/security-audit/scan?force=true`
   - 「刷新缓存读取」则不重新执行

3. **查看 5 个 Tab**
   - 配置基线 / SAST 漏洞 / 依赖 CVE / License 合规 / SBOM 清单
   - 各 Tab 可用严重度/搜索/只看高危筛选

4. **导出 SBOM**
   - 「导出 SBOM」下载 JSON 文件 → GET `/api/security-audit/sbom`

### 看到什么
- 概览卡片（总体结论/SAST高危/CVE/License/配置基线/缓存状态）+ 5 个 Tab

# 链路42：审计覆盖矩阵 & 字段契约检测 & 后台任务看板

## 第一步：审计覆盖矩阵

### 操作页面
**侧边栏** → **系统配置** → **系统管理** → **审计覆盖矩阵**

### 操作步骤

1. **重新扫描**
   - 「重新扫描」→ 扫描全部写端点 → GET `/api/admin/audit-matrix`

2. **查看 4 个 Tab**
   - 审计矩阵 / 审计日志 / 分组统计 / 最近样本
   - 矩阵 Tab 筛目标类型/仅未精确审计；日志 Tab 按动作/用户/条数查询

### 看到什么
- 概览卡片（写端点总数/能力覆盖率/实际覆盖率/类型动作覆盖/审计日志总数）+ 4 个 Tab

---

## 第二步：字段契约检测

### 操作页面
**侧边栏** → **系统配置** → **系统管理** → **字段契约检测**

### 操作步骤

1. **重新扫描**
   - 「重新扫描」→ 解析 CONTRACT.md + models.py + routers/*.py 对照 → GET `/api/admin/contract-check`

2. **查看 4 个 Tab**
   - 契约违规 / 废弃字段 / 命名违规 / 长度违规
   - 每条违规显示：表名/字段/应改为/来源（models.py 或 router）/置信度/原因

### 看到什么
- 概览卡片（高置信违规/违规总数/契约表数/模型表数/废弃字段/命名/长度/结论）+ 4 个 Tab

> 💡 字段契约（CONTRACT.md）是项目字段命名的唯一数据源，新增/修改字段必须先改 CONTRACT 再同步前后端。

---

## 第三步：后台任务看板

### 操作页面
**侧边栏** → **系统配置** → **系统管理** → **后台任务看板**

### 操作步骤

1. **查看健康摘要**
   - 总任务/运行中/失败/暂停/平均耗时/最慢任务

2. **任务管理**
   - 每任务「触发」立即手动执行、「暂停/恢复」启停、「历史」查看执行记录
   - 支持「自动刷新(5s)」轮询

### 看到什么
- 健康摘要卡片 + 任务清单表（状态/上次运行/耗时/失败率/下次运行/操作）

# 链路43：租户管理 & 开放接口 & 集成管理

## 第一步：租户管理

### 操作页面
**侧边栏** → **系统配置** → **系统管理** → **租户管理**

### 操作步骤

1. **新建租户**
   - 「+ 新建租户」→ 填名称 + 编码 + 状态 + 用户/资产配额 → POST `/tenant/api/tenants`
   - ID=1 默认租户不可删；编辑时编码锁定

2. **多租户模式**
   - 「开启/关闭租户模式」控制多租户隔离开关 → PUT `/api/system/configs`（设 tenant_mode）

### 看到什么
- 租户模式指示 + 统计卡（租户数/配额/模式）+ 租户列表

---

## 第二步：开放接口

### 操作页面
**侧边栏** → **系统配置** → **集成管理** → **开放接口**

### 操作步骤

1. **查看接口文档**
   - 基本信息面板（Base URL/认证方式/请求头/权限范围）
   - 点击接口行展开看查询参数/请求示例/响应示例

2. **管理 Token**
   - 查看 Token 列表及权限（read/write/admin）

3. **复制示例**
   - 「复制」curl 代码示例；所有请求头需带 `Authorization: Bearer <token>`

### 看到什么
- 接口列表（可折叠）+ Token 管理表 + 代码示例

---

## 第三步：集成管理

### 操作页面
**侧边栏** → **系统配置** → **集成管理** → **集成管理**

### 操作步骤

1. **新增/管理集成**
   - 配置 Elasticsearch 等外部集成（数据源对接）
   - 查看集成列表状态

### 看到什么
- 集成管理配置面板

# 链路44：通知管理 & 系统态势

## 第一步：通知管理

### 操作页面
**侧边栏** → **值班驾驶舱** → **故障处理** → **通知管理**

### 操作步骤

1. **通知渠道**
   - 「新增渠道」：类型可选 email/webhook/钉钉/企业微信/飞书/日志，按类型填 SMTP 或 Webhook 配置 → POST `/notifications/api/channels`
   - 渠道行：开关启用/编辑/测试/删除

2. **发送记录**
   - 查看历史发送记录（查询展示）

3. **升级策略**
   - 「新建策略」→ 填级别/等待时间/通知渠道（逗号分隔）→ POST `/api/sre/escalation`

### 看到什么
- 3 个 Tab：通知渠道 / 发送记录 / 升级策略

## 第二步：系统态势

### 操作页面
**侧边栏** → **值班驾驶舱** → **监控总览** → **系统态势**

### 操作步骤

1. **选择周期**
   - 切换天数 7/14/30/60 → 自动重载 → GET `/api/system/posture?days=N`

## 链路41/42 补充：用户权限 与 系统设置

### 用户管理

**侧边栏** → **系统配置** → **用户权限** → **用户管理**
- 「+ 新增用户」→ 填用户名/密码/角色/租户 → POST `/users/api/create`
- 行内下拉即时改角色 / 改租户 → POST `/users/api/{id}/set-role`、`/set-tenant`
- 修改密码：自己需旧密码+新密码（`/change-password`）；他人直接重置（`/reset-password`）
- 删除用户（当前用户不可删）

### 角色权限

**侧边栏** → **系统配置** → **用户权限** → **角色权限**
- 左侧选角色 → 右侧加载其菜单可见权限树
- 勾选/全选/清空菜单树 → 保存权限 → PUT `/api/roles/{id}/menus`
- 新建/编辑/删除角色（内置角色带「内置」徽标）

### 系统设置

**侧边栏** → **系统配置** → **系统管理** → **系统设置**
- 4 个分组：指标采集与检测 / 告警设置 / 资产健康探测 / 邮件通知 SMTP
- 修改配置项 → 一键保存 → POST `/settings/api/update`（SMTP 密码为 password 类型）

### 授权管理

**侧边栏** → **系统配置** → **系统管理** → **授权管理**
- 查看授权状态：客户/版本/签发与到期时间/最大节点数/剩余天数/机器指纹/功能模块
- 上传 `.lic` 授权文件（拖拽或点击）→ POST `/license/api/upload`
- 复制机器指纹用于签发

## 常见问题

### Q1：凭据保险库解析失败？
- **检查**：JSON 是否合法；引用名是否存在
- **检查**：解析结果是否被权限/作用域限制

### Q2：安全自查全量扫描慢？
- **说明**：首次全量扫描执行 bandit+pip-audit+pip-licenses 约 1-3 分钟，之后可「刷新缓存读取」

### Q3：租户不可删除？
- **说明**：ID=1 默认租户受保护，不可删除

### Q4：通知测试失败？
- **检查**：渠道类型对应配置（SMTP/Webhook）是否正确、升级策略渠道是否存在

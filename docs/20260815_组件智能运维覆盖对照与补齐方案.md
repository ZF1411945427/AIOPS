# 组件智能运维覆盖对照表 — AIOps vs 天穹V3.0「50 组件方案」

> 创建日期: 2026-08-15
> 对标对象: 炎龙智能天穹 V3.0「组件智能运维方案」页面 (https://www.yanlong-ai.com/solutions.html)
> 对标本质: 天穹为 **50 个基础设施组件**各提供一套「**AI智能体 + Agent Skills + MCP 工具**」的智能运维方案(监控/诊断/自动化运维闭环)。
> 本文档基于**本系统实际代码**盘点(MCP 工具 38 个 LLM 可见、数据源 10 类、技能注册表 skill_registry、各功能页)。

**图例**: ✅ 已有对应能力 | ⚠️ 有基础(数据源/SSH 可纳管)但缺专门诊断工具 | ❌ 无 | 🔧 本会话(2026-08-15)新增

---

## 一、结论速览

- **核心组件已覆盖**: MySQL / K8S / Redis / Kafka / Elasticsearch / Linux / 网络设备 / Nginx / Prometheus 已具备"AI 对话 + 工具/页面"能力(其中 Redis/Kafka/网络设备/配置漂移为本会话强化)。
- **中等缺口**: PostgreSQL / Oracle / MongoDB / RocketMQ / RabbitMQ / Nacos / etcd / Zabbix / Grafana / SkyWalking / Windows / GitLab 等——**有数据源/SSH 纳管基础, 但缺专门诊断 MCP 工具**。
- **硬缺口(❌ 无专门覆盖)**: 十余类小众/国产数据库与组件(StarRocks / Doris / TDengine / Cassandra / HBase / Kudu / Couchbase / Neo4j / NebulaGraph / ArangoDB / 南大 / 深通用 / DocumentDB / Memcached / MQTT / 物联网)。
- **产品形态差距**: 本系统"按功能域组织页面+工具"；天穹"按组件组织 50 个方案落地页, 每页配 Agent Skills + MCP 工具"。核心补法=用现有 **skill_registry 技能注册表**按组件封装技能包 + 建组件方案导航页(低成本, 不新增大量菜单)。

## 三、产品形态对齐(关键)

天穹的"50 方案"本质 = **组件的 Agent Skills + MCP 工具包 + 方案落地页**。本系统已具备完全同构的扩展底座, 只需"按组件封装 + 导航":

| 天穹 | 本系统等价底座 | 复用度 |
|---|---|---|
| Agent Skills | `skill_registry.py` + `skills/` 目录 + `use_skill` 工具 | ✅ 现成, 按组件写 SKILL.md 即可 |
| MCP 工具调用 | `mcp_registry.py` + `@register_mcp_tool` (38 个) | ✅ 现成 |
| 组件方案落地页 | Vue 页面 + 技能市场(`MarketplaceView`/`SkillCenterView`) | ✅ 现成 |
| 50 组件导航页 | **缺失** — 需一个按组件分组的方案/技能导航页 | ❌ 待建(仅 1 个页面) |

**最小成本补齐形态**: 
1. 用现有 skill 机制, 为已覆盖组件(MySQL/Redis/Kafka/K8S/ES/网络/Nginx/Linux)编写 `SKILL.md`"组件智能运维技能包"(调对应 MCP 工具)。
2. 新建 1 个「组件智能运维」导航页(技能市场 Tab), 按 50 组件分组展示"已有技能/待补技能"状态——**只加 1 个菜单, 不增加菜单混乱**。

## 四、优先级建议

| 优先级 | 动作 | 说明 |
|---|---|---|
| P0 | 为**已覆盖组件**(MySQL/Redis/Kafka/K8S/ES/网络/Nginx/Linux)封装 Skill 技能包 + 组件导航页 | 复用现成底座, 成本低、立即对齐天穹形态 |
| P1 | 补 **PostgreSQL / MongoDB / RabbitMQ / RocketMQ / Nacos / etcd** 专门诊断工具 | 常用中间件/DB, 有交易价值 |
| P2 | 补 **信创 DM / Kingbase / openGauss / OceanBase** 工具 | 信创/国产化场景高价值 |
| P3 | 长尾组件(StarRocks/Doris/Neo4j/Cassandra 等) | 按需, 非必需 |

## 五、备注

- 天穹宣传口径(50 组件全覆盖/毫秒级)为营销话术; 本表依据**能力架构与工具覆盖**实判。
- 本系统数据源 10 类(DS_TYPES: prometheus/ssh/kubernetes/docker/elasticsearch/loki/jaeger/otel/log_file/custom_api), 天然支持"SSH 通用纳管 + 专属诊断工具"叠加——**SSH 类组件(DB/中间件/服务器)无需新增数据源即可通过 `net_device_query` 同款 SSH 通道扩展诊断工具**。

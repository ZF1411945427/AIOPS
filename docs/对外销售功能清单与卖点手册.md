# AIOps 智能运维平台 —— 对外销售功能清单与卖点手册

> 用途：给潜在客户 / 渠道伙伴看的功能清单 + 卖点话术。

## 一、一句话定位

> **把"碎片化救火"变成"一站式智能运维"—— 一个平台收敛监控、告警、排障、自动化、SRE 度量，AI 助手 7×24 值班排障。**

### 给客户的第一句话（电梯话术）

> "您现在的运维是不是这样：告警一堆真真假假、故障排查靠老师傅经验、值班天天被半夜叫醒？
> 这套系统能把这三件事全自动了——**告警自动降噪、故障 AI 分析给结论、常见故障自动修复**。"

## 二、客户痛点 → 本系统解法（开场必讲）

| 客户痛点 | 本系统解法 | 客户收益 |
|---------|-----------|---------|
| 日志、指标、告警、K8s 散在 N 个系统，来回切换 | **一个平台**收敛可观测性全栈数据 | 排查不用再开 5 个窗口 |
| 故障排查靠老师傅经验，人走了知识就没了 | **AI 助手 + 知识库自动沉淀**，把每次故障的处置经验自动存档复用 | 经验沉淀到系统，不依赖个人 |
| 告警轰炸，真假难辨，麻木了 | **告警风暴检测 + 自动归并降噪** | 只看到真正要处理的告警 |
| 发现问题后要手动去修，半夜被叫醒 | **自愈规则**，告警触发自动执行修复 | 常见故障机器自己修 |
| 团队天天忙，但说不上忙出了什么价值 | **SLO / 错误预算 / 值班表 / 报表** | 用数字向老板证明团队价值 |

## 三、功能清单（按模块，每条配"卖点话术"）

### 模块 1：可观测性（监控全栈）
| 功能 | 卖点话术 |
|------|---------|
| 可视化仪表盘（可配置） | "一屏看清全公司服务健康度，老板问起来直接大屏展示" |
| 21 项系统指标采集（CPU/内存/磁盘/网络等） | "装个 agent 就能采，不用逐台配置脚本" |
| 指标趋势预测 + 异常检测 | "不是出了事才知道，是**快出事前**系统先提醒" |
| 日志采集 / 异常检测 / 日志聚类根因分析 | "日志不用人肉 grep，机器帮你找异常模式" |
| 链路追踪（OTLP/Jaeger 兼容） | "一个请求慢在哪、卡在哪一步，一眼看穿" |
| 服务依赖拓扑 + K8s 资源树 | "服务之间谁依赖谁，画成图给你看" |

### 模块 2：告警与事件（告警治理）
| 功能 | 卖点话术 |
|------|---------|
| 告警规则配置 / 抑制 / 静默 / 级别路由 | "哪些告警值得处理，规则自己定" |
| **告警风暴检测 + 自动归并降噪** | "半夜不再被 200 条重复告警轰炸，系统自动归并成 1 条" |
| 告警控制台（确认/处理/关闭） | "告警闭环管理，谁处理的、怎么处理的都有记录" |
| 事件中心 / 集群事件统计 / 异常事件检测 | "K8s 集群里发生了什么，实时掌握" |
| Webhook 对接 | "跟企业微信/钉钉/自有系统对接，告警直达 IM" |

### 模块 3：AI 智能助手（核心卖点）
| 功能 | 卖点话术 |
|------|---------|
| 自然语言对话排障 | "直接在对话框输入'看看订单服务最近怎么了'，AI 自动查指标+日志+拓扑给结论" |
| MCP 工具动态编排（查资产/告警/指标/日志/知识库/执行操作） | "AI 不是聊天机器人，是**真能调用平台所有能力的操作员**" |
| 多模型适配（OpenAI/Anthropic/MiniMax 等） | "选哪家大模型都行，不绑定厂商" |
| **RAG 知识库语义检索（资产部署文档可关联）** | "老师傅的处置经验、部署文档都在库里，AI 提问就能调出来" |
| **故障处置经验自动沉淀**（告警/故障单 → 知识草稿 → 审批入库） | "每次解决的故障自动变成知识，**越用越聪明**" |
| 提议-确认操作闭环 | "AI 要动你的系统，先给你方案，你点头才执行，安全可控" |
| 子 Agent / 工作流编排 | "复杂流程可编排成固定套路自动跑" |

### 模块 4：根因分析（6 种算法）
| 算法 | 卖点话术 |
|------|---------|
| PageRank 拓扑排序 | "故障从哪传过来的，定位源头节点" |
| Granger 因果检验 | "CPU 高是**因**还是内存高是**因**，用数据说话" |
| DTW 时序相似度 | "哪个指标曲线跟故障最像，就是嫌疑对象" |
| 日志聚类 | "海量日志自动聚成几类，异常模式自动浮出" |
| 异常子图检测 | "拓扑里哪块区域一起异常，一眼圈出来" |
| 高维降维归因 | "几百个指标里，快速锁定真正异常的维度" |

> 卖点总纲：**"6 种根因算法 + AI 助手"双保险**——算法做数据侧归因，AI 做综合判断给结论。

## 四、核心卖点总结（跟竞争对手 PK 用）

1. **AI 是真干活的，不是演示壳**——MCP 工具真实调用平台能力，能查能分析能提议执行
2. **知识会积累，越用越聪明**——故障处置自动沉淀成知识，RAG 检索复用，这是绝大多数同类产品没有的
3. **6 种根因算法 + AI 双保险**——算法算数据，AI 下结论
4. **告警降噪 90%**——风暴检测 + 自动归并，值班员不再被轰炸
5. **全链路闭环**——监控 → 告警 → 分析 → 自愈 → 度量，一条链路走完
6. **三端齐全**——Web 大屏 + 桌面 SPA + 手机 H5
7. **真环境演示**——内置两套真实故障演示环境（K8s 微服务 / 电商集群），当场打故障当场修

## 七、演示必杀技（怎么现场成交）

1. **开场先问**："您现在最头疼的运维问题是什么？"（让客户自己说出痛点）
2. **打一个真故障**：在演示环境把订单服务的 Pod 杀掉 / 磁盘塞满
3. **等告警自动出来**：展示告警降噪（一堆告警归并成一条）
4. **打开 AI 助手**：输入"订单服务最近怎么了"，AI 自动查指标+日志+拓扑给结论
5. **演示自愈**：触发自愈规则，系统自动恢复，全程不用人动手
6. **演示知识沉淀**：把这次故障存进知识库，AI 下次直接能调出来
7. **收尾反问**："这套东西帮您省下多少人力？一个月值多少钱？"

## 一、项目定位差异(本质区别)

| 维度 | 天穹 V3.0(炎龙) | 本系统 (AIOps) |
|---|---|---|
| **本质** | **Agentic AIOps 多智能体协同平台**——以"AI 智能体对话操作一切组件"为绝对主线，功能全部挂在 Agent 上 | **AIOps 中台**——功能覆盖面广(监控/告警/RCA/自动化/部署/SRE)，Agent 是众多能力之一 |
| **定位口号** | "AI 智能体运维，大模型驱动的 Agentic AIOps 多智能体协同运维平台" | "监控·告警·RCA·自动化·部署·SRE 一站式运维平台" |
| **技术栈** | 大模型(DeepSeek/GPT-4o/Qwen/Kimi) + 知识图谱 + 图神经网络 + 强化学习 + 分层微服务 | Python FastAPI + Vue3 + SQLite + 自研调度 + 本地 BGE/Milvus RAG |
| **组件覆盖** | 30+ 组件(关系型/NoSQL/国产DB/中间件/缓存/虚拟机/超融合/网络/云原生/物联网)全部对话化 | 资产/K8s/指标/日志/链路/告警/数据库数据源等，组件对话管控不完整 |
| **AI 深度** | LLM 因果推断 + GNN + 注意力机制 + 强化学习(宣传口径) | 真 tool-calling 多轮循环 + 本地 RAG 混合检索 + AI 自主部署执行(L4/L5) |

**一句话**: 天穹是"Agent 为王的组件对话管控平台"，本系统是"功能大而全的运维中台"。**本系统在真实部署执行、RAG 检索、深度 RCA 上可能更强；但天穹在"全组件对话化管控 + 配置智能 + 业务影响 + 工程师助手"的 Agent 覆盖面上更系统化。**

## 二、功能层面:本系统有而天穹没有(优势项)

这些本系统**已经具备或更强**，不是差距，但完整列出:

1. **AI 自动部署引擎(最大亮点)**: `deploy_service.py` L4/L5 自主执行——AI 解析 SOP → 自动推断环境 → 自主生成命令 → fix/retry/rollback 决策 → 健康门控 → 特征学习。天穹的"智能化配置/部署"侧重配置调参，而**本系统能真实把 docker compose 项目部署上线**。
2. **离线仓库 + K8s 离线集群一键部署**: offline_repo_service + k8s_offline_deploy(7 阶段 kubeadm 编排)。天穹无离线一键建集群能力。
3. **深度根因分析算法全家桶**: 6 种 RCA 算法 + 跨域 RCA + 自动调查 + log_rca/idice。天穹宣传"根因分析"但其因果推断多为黑盒。
4. **本地 RAG 混合检索**(BM25+向量+reranker + Milvus/BGE)，天穹未披露本地知识库能力细节。
5. **edge agent 反向隧道 + 部署执行通道**(route_exec 隧道优先/SSH 回退)，天穹无边缘 Agent 反向接入。
6. **移动端 UniApp + IM ChatOps + 值班表 + 混沌工程/SLO/Error Budget**: 天穹无移动端/SRE 套件。
7. **License 授权、双库(demo/real)、安全审计、敏感字段掩码**: 天穹侧重等保 2.0 合规，非其亮点。

## 四、本系统领先领域(应持续保持)

1. **真实 AI 部署执行力**: 天穹的"自愈/部署"偏配置类，本系统是真能把项目 `docker compose` 跑起来的 L4/L5 引擎。
2. **RAG 知识底座**: 本地向量混合检索 + 知识自动沉淀，比天穹的"模型即插即用"更贴合私有化。
3. **离线交付能力**: 离线仓库 + K8s 离线集群 + License 私有化，契合信创/内网场景。
4. **RCA 深度**: 6 种算法 + 日志/链路 RCA + 自动调查回写，工程化程度高。
5. **移动端 + ChatOps**: 移动运维 + IM 机器人，天穹无。

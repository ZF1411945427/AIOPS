# AIOps 用户操作手册 — 链路37-40：Agent运维 & AI部署编排 & IM ChatOps & AI数据能力

> **适用角色**：运维工程师、AI 平台管理员、SRE
> **前置条件**：已登录系统，拥有相关菜单权限
> **预计耗时**：约 30-40 分钟

---

## 概述

本手册覆盖四条链路（补齐 Agent 运维与 AI 能力类功能页）：

- **链路37**：Agent 下发监控 + Agent 自主巡检 + 子智能体管理
- **链路38**：AI 自动部署 + 智能体编排 + 智能体配置

- **链路40**：AI 数据能力（容量预测 / 特征仓库 / 外部 CMDB / RAG 重排 / 智能体审计）

> **链路37 Agent运维**　①下发Agent → ②自主巡检 → ③子智能体
> **链路38 AI编排**　①AI自动部署 → ②智能体编排 → ③智能体配置

> **链路40 AI数据**　①预测模型 → ②特征仓库 → ③外部CMDB → ④RAG重排

# 链路37：Agent 下发监控 & 自主巡检 & 子智能体

## 第一步：Agent 下发监控

### 操作页面
**侧边栏** → **Agent 管理** → **Agent 运维** → **Agent 下发监控**

### 操作步骤

1. **下发 Agent**
   - 「下发」页：选可部署资产（SSH 凭证就绪）→「下发 Agent」→ 填云端地址 `cloud_url` → 确认，弹进度轮询 → POST `/agent/deploy`

2. **监控**
   - 「监控」页：查看已注册 agent 在线状态，「指标」/「命令」

3. **命令执行**
   - 「命令执行」：选资产 → 输命令 → 执行（隧道优先，SSH 回退）→ POST `/agent/exec`

### 看到什么
- 4 个 Tab：Agent 下发 / Agent 监控 / 命令执行 / 执行日志

---

## 第二步：Agent 自主巡检

### 操作页面
**侧边栏** → **Agent 管理** → **Agent 运维** → **Agent 自主巡检**

### 操作步骤

1. **触发巡检**
   - 点「立即巡检」手动触发（默认 5 分钟自动循环）→ POST `/agent/autonomous/trigger`

2. **查看历史与动作**
   - 「巡检历史」点「详情」→ 查看发现的问题与执行动作

### 看到什么
- 4 个统计卡（巡检/问题/动作/成功）+ 2 个 Tab（巡检历史/动作日志）

---

## 第三步：子智能体管理

### 操作页面
**侧边栏** → **Agent 管理** → **Agent 运维** → **子智能体管理**

### 操作步骤

1. **路由测试**
   - 顶部路由测试窗：输入问题 → 点「路由」→ POST `/agent/sub-agents/route`，验证命中哪个子专家

2. **编辑子智能体**
   - 点卡片「✎ 编辑」→ 填 display_name/关键词/System Prompt/工具白名单（点击切换）→ 保存 → PUT `/agent/sub-agents/{id}/edit`

3. **重新播种预置**
   - 「🔄 重新播种预置」恢复默认专家

### 看到什么
- 子专家概览卡 + 路由测试窗 + 子专家清单（可展开看 Prompt 与工具白名单）

# 链路38：AI 自动部署 & 智能体编排 & 智能体配置

## 第一步：AI 自动部署

### 操作页面
**侧边栏** → **Agent 管理** → **Agent 运维** → **AI 自动部署**

### 操作步骤

> AI 自动部署为多步流水线，含 5 个 Tab：SOP 步骤 / 环境映射 / 预检 / 执行 / 报告。

1. **新建部署计划**
   - 填名称、目标资产（多选）、`artifact_path`、上传/粘贴部署手册

2. **SOP 解析**
   - 「AI 解析手册」→ 生成结构化 SOP 步骤 → POST `/api/plans/{id}/parse`

3. **环境映射**
   - 「📦 下载源码」→「🔍 环境探查」→「⚙️ AI 自动分析」→「解析环境映射」→ 编辑映射值保存

4. **预检**
   - 「执行预检」→ 检查环境就绪 → POST `/api/plans/{id}/preflight`

5. **执行部署**
   - 「开始部署」→ WebSocket 实时终端，遇高危操作弹「风险确认」，可「停止」/「🧹 回滚清理」→ POST `/api/plans/{id}/execute`

6. **报告**
   - 「部署后验证」+「生成报告」+ 下载 Word/HTML

### 看到什么
- 计划卡片网格 + 详情模态 5 Tab；执行采用 AI 决策引擎 + 高危人工确认门控

---

## 第二步：智能体编排

### 操作页面
**侧边栏** → **Agent 管理** → **Agent 运维** → **智能体编排**

### 操作步骤

1. **拖拽搭建工作流**
   - 从左侧节点面板拖 10 种节点（LLM/知识库/工具/条件/代码/HTTP/notify/子代理）到画布，拖边缘连线

2. **配置节点**
   - 点节点在右侧属性配置；点「⏰ 触发器」配置 manual / cron / alert_auto 三种触发

3. **保存 / 发布**
   - 「保存」存草稿、「发布」上线 → POST `/api/workflows/create|update`

4. **运行测试**
   - 「运行测试」输入参数调用，轮询执行状态，遇 tool 节点「确认/取消」；自动执行切换需二次风险确认

### 看到什么
- Vue Flow 画布 + 左侧节点面板 + 右侧属性抽屉 + 触发器/运行测试弹窗

---

## 第三步：智能体配置

### 操作页面
**侧边栏** → **Agent 管理** → **Agent 运维** → **智能体配置**

### 操作步骤

1. **模型提供商管理**
   - 提供商表：「+ 新增 / 编辑 / 测试 / 禁用 / 删除」
   - 「刷新健康度」「重置熔断」→ POST `/ai/api/providers/{id}/test`、`/reset-breaker`
   - 编辑时 API Key 留空不修改（敏感字段契约）

2. **Agent 配置**
   - 「+ 新增配置」设系统提示词/允许执行/需确认/历史消息数 → POST `/ai/api/configs/create`

### 看到什么
- 「模型提供商」表 + 「Agent 配置」表 + 底部表单弹窗

# 链路39：IM 双向通道（ChatOps）

## 操作页面
**侧边栏** → **Agent 管理** → **Agent 运维** → **IM 双向通道**

## 操作步骤

1. **配置通道**
   - 先在「通知管理」建飞书/钉钉/企微通道 → 回本页启用「双向」切换

2. **设默认子专家**
   - 每通道设默认子专家（自动路由 / 指定）→ POST `/im/channels/{id}/configure`

3. **配置签名密钥**
   - 「⚙️ 配置签名密钥」填 Verify Token / Encrypt Key 等

4. **测试回推**
   - 「📡 测试回推」验证通道连通 → POST `/im/test-reply/{id}`

## 看到什么
- 「双向通道配置」卡片列表 + 「最近 IM 消息」+ 「支持指令」（/ai /alert /help）

# 链路40：AI 数据能力

> **预测模型已提供正式菜单入口**（侧边栏 → 智能分析室 → 指标监控 → **容量预测**）。以下其余功能页（特征仓库/外部 CMDB/RAG 重排/智能体审计）当前仍**无独立侧边栏菜单入口**（孤儿页），通过 URL 或相关页面跳转访问。

## 第一步：容量预测（预测模型）

### 操作页面
**侧边栏** → **智能分析室** → **指标监控** → **容量预测**

### 操作步骤

1. **新建预测模型**
   - 填名称、指标、模型类型（linear / polynomial / rolling_avg）、参数 → POST `/prediction-models/api/create`
2. **运行预测**
   - 「运行全部预测」→ GET `/api/predict-all`；预测结果含未来 48h 曲线
3. **管理模型**
   - 预测 / 禁用 / 删除；预测结果弹窗展示趋势

### 看到什么
- 模型卡片网格（分页）+ 新建弹窗 + 预测结果弹窗（未来 48h 曲线）

## 第二步：特征仓库

- **入口**：如 `/feature-store`（无菜单）
- 「添加特征」（feature_name/entity_type/entity_id/value/source）→ POST `/feature-store/api/add`
- 按名称/类型/ID 查询 → POST `/api/query`

## 第三步：外部 CMDB

- **入口**：如 `/ext-cmdb`（无菜单）
- 新增配置（类型 generic|cmdb/zabbix/nacos、API URL、同步间隔、认证 JSON）→ POST `/ext-cmdb/api/create`
- 启用/同步/删除

## 第四步：RAG 重排

- **入口**：如 `/rag-rerank`（无菜单）
- 输 query + 选重排模式（不重排 / 经典 classic / 智能 smart）→ 检索 → GET `/knowledge/v2/search`
- 对比向量 / BM25 / 重排分

## 第五步：智能体审计

- **入口**：如 `/audit`（无菜单）
- 查看 8 个统计卡（总调用/成功率/耗时/P95/会话/消息/待确认/活跃工具）+ 工具调用分布 + 近 7 日成功率趋势
- GET `/agent/stats`、`/agent/invocations`

## 补充：智能体工作流执行监控

- **入口**：如 `/agent-workflow/runs`（无独立菜单，孤儿页）
- 从「智能体编排」页运行的工作流实例，在此监控执行状态（顶栏标题"智能体工作流执行监控"）
- 状态筛选 + 刷新；执行实例表格（状态/触发源/节点进度/下载报告/中止）
- 详情查看每节点输出/错误；待确认节点「确认/取消」；失败节点「重试」；执行中「中止」；「下载报告」导出 PDF
- GET `/agent-workflow/api/runs`、`/api/runs/{run_id}`、`/api/runs/{run_id}/pdf`

> ⚠️ **入口缺失说明**：以上功能页（特征仓库/外部 CMDB/RAG 重排/智能体审计/智能体工作流执行监控）组件已在系统注册但未挂在侧边栏菜单。若需要正式使用，需在 `menu_config.json` 补充菜单项。

## 常见问题

### Q1：Agent 下发失败？
- **检查**：目标资产 SSH 凭证是否就绪、云端地址是否正确、目标机网络连通

### Q2：AI 自动部署执行被拦截？
- **检查**：是否触发了高危风险确认门控（需人工确认后才继续）
- **检查**：预检是否通过、环境映射是否完整

### Q3：IM 测试回推失败？
- **检查**：通知管理是否已先建对应通道、签名密钥（Verify Token/Encrypt Key）是否正确

### Q4：孤儿页访问不到？
- **说明**：特征仓库/外部 CMDB/RAG 重排/智能体审计当前无菜单入口，需通过 URL 或补充菜单项访问（容量预测已提供正式菜单）

## 专业术语

| 术语 | 英文 | 说明 |
|------|------|------|
| Agent 下发 | Agent Deploy | 向目标资产下发并注册 agent，实现隧道优先的命令执行 |
| 自主巡检 | Autonomous Inspection | Agent 周期自我巡检发现问题并执行动作 |
| 子智能体 | Sub-Agent | 按领域划分的专家代理，支持关键词路由 |
| 智能体编排 | Agent Orchestration | 可视化搭建多节点智能体工作流 |
| ChatOps | IM ChatOps | 通过 IM（飞书/钉钉/企微）实现双向运维交互 |
| 孤儿页 | Orphan Page | 已注册但无菜单入口的页面 |
